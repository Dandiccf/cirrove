Remove Cirrove data and Google access

Local connection data, keyring credentials and Google's authorization are separate. Complete each applicable step below.

  1. 1

    Remove the connection

    In Cirrove, select the connection and choose Remove. From a terminal, the equivalent command is: 

    cirrove forget <name>

    Cirrove stops the connection and places its local state under the removed-data area for one hour so an accidental removal is recoverable. This does not delete files from Google Drive.

  2. 2

    Discard the removed local data

    Review the space in use, then permanently discard data only for connections already removed:

    cirrove local-data
cirrove local-data --discard-removed

    This removes Cirrove's local index, cached content and retained working data for those removed connections.

  3. 3

    Delete the local sign-in grant

    Open your desktop's password and keyring manager. Find credentials labelled Cirrove for the removed connection and delete them. Removing or uninstalling the app does not perform this keyring step automatically.

  4. 4

    Revoke Google access

    Open your Google Account's third-party connections, select Cirrove and remove its access. This invalidates the Google-side authorization independently of the local cleanup.

Do not delete through the mounted drive to clean up Cirrove. When changes are allowed, deleting items inside the mounted folder moves those items to Google Drive's trash. Use the steps above for local cleanup.

Uninstalling packages

Uninstalling removes Cirrove's installed program files. It does not by itself remove connections, local state, cached content, pending changes, keyring grants or Google's authorization. Perform the removal sequence first if you want those items removed too.
