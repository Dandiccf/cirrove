Google Drive access

You choose the drive and the access mode

01

Select one collection

Each connection presents one Google My Drive or Shared Drive. Cirrove indexes its names and metadata locally so the filesystem remains responsive.

02

Open or keep files

File bytes are fetched directly from Google when opened. You can pin selected files or folders to the local cache for offline use.

03

Allow changes only when needed

Read-only mode requests Drive read access. Turning on Allow changes requests permission to create and change ordinary files in the selected collection.

Clear boundaries

What the preview supports

Ordinary files can be read and, when you opt in, created, saved, renamed, moved and moved to Google Drive's trash.

Google Docs and Sheets appear as read-only export packages. Cirrove does not write back changes to native Google documents.

Your files travel directly between this desktop app and Google. Cirrove does not operate a server that receives their contents.

Your control

See what stays local and remove it

Account details, metadata, cached content and sign-in credentials stay on your computer. The removal guide explains how to remove a connection, discard its local data, delete its keyring grant and revoke Google access.
